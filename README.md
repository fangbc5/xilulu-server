# xilulu-server

这是基于 Rust 语言编写的高性能微服务后端工程。包含了一套微服务治理系统，主要提供了即时通讯、身份认证、团队管理和网关转发等功能。

## 微服务模块结构

项目采用 Cargo 虚拟工作区 (Virtual Workspace) 管理多个相互协调的微服务和一个核心基础框架模块 (fbc-starter)。

### 基础核心层
- `fbc-starter`：提供了依赖注入、数据库连接池、Nacos 服务注册、缓存管理、全局配置、Http 响应封装等核心能力和工具链。

### 业务微服务层
- `ms-auth`：基础权限校验与 Token 管理
- `ms-identity`：身份和账号的统一管理中心（用户、密码安全检查、租户管理等）
- `ms-im`：即时通讯服务核心逻辑支撑（聊天会话、好友申请与管理、消息中心）
- `ms-websocket`：即时通讯连接维持与 WebSocket 实时推送系统架构中心
- `ms-team`：组织架构与团队管理服务（包含部门、员工、组织架构树维护等）
- `ms-oss`：对象存储，处理文件上传、文件存储（如头像、媒体文件上传与下载代理）
- `ms-notify`：通知网关封装组件
- `ms-ai`：实验性人工智能相关业务封装与对接接口

## 环境与启动

1. 项目基于异步运行时 `Tokio`，Web 框架采用 `Axum`，数据 ORM 使用了原生的 `sqlx` 与封装层 `sqlxplus`。
2. 基础组件中间件需启动 Nacos（作为注册中心及配置中心）、MySQL 8、Redis（作为分布式缓存）等。
3. 可在项目根目录使用 `docker compose up -d` 命令快速拉起所有包含的服务和中间件测试环境运行。
4. 各服务可以直接通过 `cargo run -p ms-<服务名>` 直接运行（需确保对应服务下的 `.env` 环境变量已正确配置连接信息）。
