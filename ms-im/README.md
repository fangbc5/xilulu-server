# ms-im

即时通讯系统微服务 — Xilulu 的核心即时通信枢纽，承担亿级即时流消息的持久化沉淀与漫游下发。

## 功能边界

- 💬 **私聊/群聊双轨制** — 完备的消息互传机制及离在线推送状态转换
- 👥 **社群与关系链** — 维护用户单向/双向好友申请与拉黑拦截规则
- 🗄️ **消息持化与漫游** — 支持基于游标 Seq 的断线增量消息拉取与阅读游标同步
- ⚡ **消息队列解耦** — 通过 Kafka 在不同节点、网关与持久化引擎间解耦

## 开发说明

本服务负责 IM 消息的后端逻辑清洗、合规落库及转发逻辑。网络长连接的维护请参看 `ms-websocket` 这个孪生接入模块。
